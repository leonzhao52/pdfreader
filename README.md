# PDF 阅读器

> 轻量、快速、专注阅读体验的 Windows 桌面 PDF 阅读器

基于 Electron + PDF.js 构建，专为日常阅读文档、论文、电子书设计。

---

## ✨ 功能特性

### 📖 基础阅读
- ✅ **打开文件** - 文件对话框 / 拖拽文件到窗口
- ✅ **高质量渲染** - 基于 PDF.js，文字清晰
- ✅ **缩放控制** - 滚轮 / 按钮，范围 50% ~ 400%
- ✅ **翻页导航** - 上一页 / 下一页 / 页码跳转
- ✅ **全屏阅读** - 一键进入 / 退出全屏（F11）
- ✅ **缩略图导航** - 侧边栏显示页面缩略图，点击跳转

### 🎯 阅读体验
- ✅ **进度记忆** - 自动记住每个文件最后阅读位置
- ✅ **文件列表** - 最近打开列表（最多20个），快速打开
- ✅ **双页模式** - 并排显示两页，适合宽屏阅读
- ✅ **夜间模式** - 深色主题护眼，一键切换

### ⌨️ 快捷键
| 快捷键 | 功能 |
|--------|------|
| `Ctrl+O` | 打开文件 |
| `←` / `→` | 上一页 / 下一页 |
| `Ctrl+=` / `Ctrl+-` | 放大 / 缩小 |
| `Ctrl+0` | 重置缩放（100%） |
| `F11` | 全屏切换 |
| `Esc` | 退出全屏 |

## 🚀 快速开始

### 环境要求
- Windows 10/11
- Node.js 16+ （[下载](https://nodejs.org/)）
- npm（Node.js 自带）

### 安装依赖

```bash
# 进入项目目录
cd pdfreader

# 安装依赖（国内用户建议配置镜像加速）
npm install
```

**国内镜像配置**（可选，加速安装）：

```bash
# 设置 Electron 镜像
npm config set ELECTRON_MIRROR https://npmmirror.com/mirrors/electron/

# 设置 npm 镜像
npm config set registry https://registry.npmmirror.com
```

### 启动应用

```bash
# 开发模式启动
npm start

# 或启用开发者工具
npm run dev
```

## 📖 使用说明

### 打开PDF文件
1. 点击工具栏「📂 打开」按钮
2. 或按快捷键 `Ctrl+O`
3. 或将PDF文件拖拽到应用窗口

### 翻页操作
- **工具栏**：点击「◀」「▶」按钮
- **键盘**：按 `←` `→` 方向键
- **页码跳转**：在页码输入框输入页码后回车
- **缩略图**：点击侧边栏缩略图跳转

### 缩放控制
- **工具栏**：点击「+」「-」按钮
- **键盘**：按 `Ctrl+=` 放大，`Ctrl+-` 缩小
- **重置**：按 `Ctrl+0` 恢复100%
- **适应宽度**：点击「适应」按钮

### 双页模式
- 点击工具栏「双页」按钮切换
- 左页显示当前页，右页显示下一页
- 适合宽屏显示器阅读论文、书籍

### 夜间模式
- 点击工具栏「🌙」按钮切换
- 深色主题，减少眼睛疲劳
- 设置会自动保存

### 阅读进度
- 自动保存每个文件的阅读位置
- 重新打开文件时自动恢复到上次页码
- 在侧边栏「文件」标签查看所有文件进度

## 🐛 常见问题

### Q: 启动时报错 "Electron failed to install correctly"
**A**: Electron 二进制文件下载失败，尝试：
```bash
# 删除并重新安装
rm -rf node_modules
npm install
```
国内用户请配置镜像（见快速开始部分）。

### Q: 打开PDF时显示"文件不存在"
**A**: 文件可能已被移动或删除，应用会自动从最近列表中移除失效文件。

### Q: 双页模式下最后一页显示异常
**A**: 正常现象，最后一页为奇数页时，右侧为空白。

### Q: 如何卸载应用？
**A**: 直接删除项目文件夹即可，配置文件在 `%APPDATA%/pdfreader/`，可一并删除。
